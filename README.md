# QR redirects

Short folders (used by the engraved QRs): nw = Namore WhatsApp, nm = Namore Menu, bw = Bakery WhatsApp, bm = Bakery Menu. Long-name folders are older copies.

Each folder = one QR code. To change where a QR goes, edit the link in that folder's index.html (3 places) and commit.
